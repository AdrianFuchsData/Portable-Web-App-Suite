# Übersicht

`overview.html` enthält **alle Anwendungen der Suite in einer Datei** (etwa 90 MB, das meiste davon das
Python-Notebook). So kommt die Suite am einfachsten auf einen Rechner: eine Datei kopieren, öffnen und jede Anwendung
von dort starten.

## Anwendungen starten

Die Startseite zeigt die Anwendungen nach Bereichen. Für jede Anwendung:

| Schaltfläche | Funktion |
|---|---|
| Öffnen | startet die Anwendung in einem neuen Tab der Übersicht |
| ↗ | startet die Anwendung in einem neuen Browserfenster |
| 💾 | speichert die Anwendung als eigene HTML-Datei (z. B. `texteditor.html`) |

Die Tabs oben wechseln zwischen der Startseite (▦ Anwendungen) und den laufenden Anwendungen; diese behalten ihren
Zustand beim Wechseln. Ein Punkt (•) kennzeichnet ungespeicherte Änderungen; das Schließen eines solchen Tabs (×) oder
der Übersicht fragt vorher nach.

## Anwendungen speichern

**Alle Anwendungen speichern…** speichert jede Anwendung als eigene HTML-Datei: in Chrome und Edge in einen Ordner Ihrer
Wahl, in anderen Browsern als Download `portable-web-app-suite.zip`. Einzelne Dateien eignen sich für Rechner, die nur
einige Anwendungen brauchen, oder um eine Anwendung direkt zu öffnen. Aus einzelnen Dateien gestartete Anwendungen
können weiterhin Dateien untereinander weitergeben, wenn sie **mit ihren ursprünglichen Namen in einem Ordner** liegen
(siehe „Öffnen mit…“ im Benutzerhandbuch).

## Dateien öffnen

**Datei öffnen…** (oder eine Datei auf die Startseite ziehen) fragt, mit welcher Anwendung die Datei geöffnet werden soll,
und startet diese in einem Tab. In Chrome und Edge schreibt Speichern in dieser Anwendung direkt in die Datei.

## „Öffnen mit…“ zwischen Anwendungen

In der Übersicht gestartete Anwendungen öffnen Dateien aus anderen Anwendungen (zum Beispiel eine Datei in einem Archiv,
eine Datei auf einem SFTP-Server, einen E-Mail-Anhang) in einem neuen Tab. Speichern schreibt die Datei dorthin zurück,
woher sie kam.

## Tastenkürzel

Auf dem Mac verwenden Sie Cmd statt Strg. `F1` (oder `?`) zeigt diese Liste in der Anwendung.

### Hilfe

| Tasten | Funktion |
|---|---|
| `F1` / `?` | diese Liste zeigen (außerhalb von Textfeldern) |

## Auf Smartphones und Tablets

Die Startseite zeigt eine Anwendung pro Zeile; die Tabs lassen sich seitlich verschieben. Anwendungen laufen in voller
Breite unter den Tabs. Viele gleichzeitig geöffnete Anwendungen brauchen viel Speicher; schließen Sie Tabs, die Sie
nicht mehr brauchen.
