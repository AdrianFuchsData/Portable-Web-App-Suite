Office, file, security, data science and network tools that run completely in the browser. **Every application is a single HTML file**: download it, open it in Chrome, Edge or Firefox, done. No installation, no administrator rights, no server, no internet connection needed. It also works on thin clients with only a browser, and on Windows, Linux and Android.

## What's new since 1.4.0

**New application: Authenticator** (`authenticator.html`) – two-factor codes (TOTP, HOTP, Steam) from your own KeePass database: previous, current and next code, an adjustable clock for servers whose time differs, import from `otpauth://` links, Google Authenticator exports, Aegis, QR code pictures, the camera or the clipboard, export as QR codes and links. The tokens are stored as KeePassXC and KeePass 2 store them.

**Files**
- **Text editor**: Markdown preview, syntax checks for JSON, XML and YAML (JSON ↔ YAML), more line tools (shuffle, number, keep or remove lines, wrap at a width), bookmarks.
- **Hex editor**: the structure of known formats (PNG, JPEG, ZIP, ELF, PE, …), coloured marks, byte statistics and entropy.
- **Archive manager**: search inside the files of an archive, compare two archives, split archives into parts and open split archives.
- **Media player**: audio visualisation. **Diagram editor**: PlantUML diagrams and templates.
- **Barcodes**: captions with the code, and batch creation from a CSV or text file as a PDF label sheet or a ZIP.

**Security**
- **KeePass**: CSV import and export, entry history (compare, restore, delete), one-time passwords (KeePassXC and KeePass 2 fields), QR codes to move a secret between devices.

**Office**
- **PDF viewer**: select and copy text, redaction that removes the content, pages as pictures, compress.
- **Calendar**: tasks (to-dos), CSV import and export, CalDAV calendars through the relay.
- **Web slides**: PDF export without the print dialog; a theme editor (colours, background, fonts, sizes).

**Network**
- **Mail**: search across all folders and accounts; mbox export and import.
- **Database tool**: MySQL/MariaDB; CSV and spreadsheet import and export; better SQL completion.
- **FTP/SFTP**: permissions, preview, edit a remote file.
- **SSH**: saved snippets, proxy and jump hosts, port forwarding through the relay.
- **HTTP analyzer**: collection runner with data files, code generation in 11 languages, GraphQL with a schema explorer.
- **Web inspector**: accessibility check (axe-core).

**All applications**
- **Icons** that are part of the suite replace the emoji and symbol characters on the buttons, so they look the same in every browser.
- The **title bar can be hidden**, and on phones the **toolbar can be collapsed** – more room for the content.
- **Install as an app (PWA)**: served by the relay (on `localhost` or over `https`), the suite and each application can be installed with
  its own icon and window, and an installed app also starts when the relay does not run.
- **Search and replace** in the code editors (text editor, notebook, database tool, HTTP analyzer) in the suite's own layout, with the
  number of matches.
- **Touch screens**: the audio editor follows the usual gestures (drag to move, two fingers to zoom, hold to select); in the diagram
  editor one finger moves the drawing.
- **Presentation**: a right click (or a long press) opens the application's context menu.
- **Notebook**: the Python package `cryptography`; `requests` through the relay returns decompressed content, as in Python and Jupyter.

**Fixed**
- Switching the language no longer closes the applications open in the overview; they follow the language.
- Text editor: the font menu shows the chosen font, and every font choice takes effect.
- Document editor: *Insert → Header & footer* works in new documents (they now have A4 pages, as in Word).
- Audio editor: playback recovers when the browser loses the audio output (Chrome: “The AudioContext encountered an error …”), and the
  waveform follows when the view scrolls during playback.

The **relay** is updated (listening mode for port forwarding, installing as an app): use the one of this release.

## Good to know

- **Small and medium files:** the applications keep their data in the browser's memory, so what they can handle is limited by the memory of one browser tab. They are made for everyday files, not for big data.
- **Saving:** in Chrome and Edge, saving writes directly to the opened file. Firefox downloads a new copy, which you then use to replace the old file.
- **Office files:** charts, cropped pictures and videos are kept; charts are written as pictures with their data (not as native Office charts). Keep the original file until you have checked the result.
- **Network functions** (SSH, FTP/SFTP, e-mail, PostgreSQL, MySQL, CalDAV, network from Python) need the small **relay** program on your computer, because browsers cannot open such connections themselves. It runs without installation or administrator rights: [`relay/python/relay.py`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.0/relay/python/relay.py) (Python) or [`relay/powershell/relay.ps1`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.0/relay/powershell/relay.ps1) (PowerShell). All other functions work without it.
- **Settings** are stored per origin: applications opened as files and applications served by the relay keep separate settings (move them with **⚙ Settings** → Export / Import, or with a workspace).
- **Help:** press `F1` in any application. Documentation: [user guide](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.0/docs/en/user-guide.md), [Benutzerhandbuch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.0/docs/de/benutzerhandbuch.md).
