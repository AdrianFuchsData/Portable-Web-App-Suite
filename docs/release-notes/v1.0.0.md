Office, file, security, data science and network tools that run completely in the browser. **Every application is a single HTML file**: download it, open it in Chrome, Edge or Firefox, done. No installation, no administrator rights, no server, no internet connection needed. It also works on thin clients with only a browser, and on Windows, Linux and Android.

## Good to know

- **Saving:** in Chrome and Edge, saving writes directly to the opened file. Firefox downloads a new copy, which you then use to replace the old file.
- **Network functions** (SSH, FTP/SFTP, e-mail, PostgreSQL) need the small **relay** program on your computer, because browsers cannot open such connections themselves. It runs without installation or administrator rights: [`relay/python/relay.py`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.0.0/relay/python/relay.py) (Python) or [`relay/powershell/relay.ps1`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.0.0/relay/powershell/relay.ps1) (PowerShell). All other functions work without it.
- **Spell checking** in all text fields, with English (US) and German built in.
- **Credentials and settings** stay on your computer: as a JSON file, or encrypted in a KeePass database.
- **Help:** press `F1` in any application. Documentation: [user guide](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.0.0/docs/en/user-guide.md), [Benutzerhandbuch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.0.0/docs/de/benutzerhandbuch.md).
