Office, file, security, data science and network tools that run completely in the browser. **Every application is a single HTML file**: download it, open it in Chrome, Edge or Firefox, done. No installation, no administrator rights, no server, no internet connection needed. It also works on thin clients with only a browser, and on Windows, Linux and Android.

## What's new since 1.0.0

**Diagrams everywhere**
- **Diagrams in presentations, web slides, documents and spreadsheets:** *Insert diagram* opens the diagram editor; every *Save* there updates the picture. Diagrams are stored as ordinary PNG pictures with the draw.io diagram inside, so PowerPoint, Word, Excel and LibreOffice show them and they stay editable here and in draw.io. *Edit diagram* opens a selected one again; an updated picture keeps its scale.
- **Diagram editor:** nested groups, an element tree in the sidebar (select, fold, rename), rotation of shapes, editing labels of elements, groups and layers. A diagram opened from a `.drawio.png` / `.drawio.svg` picture is saved as such a picture again. Routing points of draw.io connectors are kept and drawn.

**Editing**
- **Emoji and symbol picker** in every text field (`Ctrl+.` or the ☺ button, which can be switched off in the global settings; optional conversion of emoticons such as `:-)`).
- **Colour picker** of the suite for every colour field (with recently used colours, opacity and keyboard control; the browser's own picker can be chosen in the settings). In the text editor, colours in the text get a swatch that opens it.
- **Text editor:** SQL formatting, SAS syntax highlighting, configurable indentation (spaces or tabs, width) and Tab key behaviour.
- **Notebook:** raw cells (for nbconvert) are kept and saved (`R` makes a cell raw).

**Files**
- **Open several files at once** from the archive manager and the FTP/SFTP client (*Open with…*), for example in hex editor tabs.
- **Text and hex editor:** a dropped newer version of a file that is open unchanged replaces it (before, the old content was shown).
- **Documents:** extremely long words (more than 20,000 characters without a space, such as pasted base64 data) are shown instead of breaking the editor.

**Fixes**
- AES encrypted ZIP archives are now interoperable with 7-Zip and other programs.
- Hex editor: *Open with…* from other applications works.
- Text editor: the line-based comparison (diff) shows changed lines correctly.
- Presentation editor: a damaged PPTX without readable slides is reported instead of breaking the editor.
- Image editor: a damaged OpenRaster file is reported instead of producing empty layers.
- Archive manager: 7z archives can only be written with ASCII file names (the built-in 7z writer cannot store other characters); the archive manager now says so and suggests ZIP or TAR instead of writing garbled names.

**Security**
- **Web slides block scripts in slides.** Presentations can contain HTML, and HTML can contain scripts. Scripts from slides no longer run unless you allow them: opening a presentation with scripts asks whether to trust it, and the toolbar shows the state (**🛡 Scripts blocked** / **⚠ Scripts allowed**). Only allow scripts for files you trust – they then run with the rights of the application.
- `javascript:` links from opened files never run: not in printed documents, not as diagram images, and not when a document, spreadsheet, PDF or e-mail opens a link.
- The test suite now opens malicious files in every application, fuzzes all file readers with damaged files, and checks saved files with LibreOffice, 7-Zip, ffprobe, pdfinfo, SQLite and other software.

## Good to know

- **Saving:** in Chrome and Edge, saving writes directly to the opened file. Firefox downloads a new copy, which you then use to replace the old file.
- **Network functions** (SSH, FTP/SFTP, e-mail, PostgreSQL) need the small **relay** program on your computer, because browsers cannot open such connections themselves. It runs without installation or administrator rights: [`relay/python/relay.py`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.1.0/relay/python/relay.py) (Python) or [`relay/powershell/relay.ps1`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.1.0/relay/powershell/relay.ps1) (PowerShell). All other functions work without it.
- **Spell checking** in all text fields, with English (US) and German built in.
- **Credentials and settings** stay on your computer: as a JSON file, or encrypted in a KeePass database.
- **Help:** press `F1` in any application. Documentation: [user guide](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.1.0/docs/en/user-guide.md), [Benutzerhandbuch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.1.0/docs/de/benutzerhandbuch.md).
