Office, file, security, data science and network tools that run completely in the browser. **Every application is a single HTML file**: download it, open it in Chrome, Edge or Firefox, done. No installation, no administrator rights, no server, no internet connection needed. It also works on thin clients with only a browser, and on Windows, Linux and Android.

## What's new since 1.5.0

A patch release for running the suite as a **public online service**: anyone may use the applications, the network functions are
for your own users only.

- **Documentation: a public online service** – nginx serves the applications, the relay behind it only its API for users with an
  account. With templates for the systemd service and the nginx site, what each option is for, how to update, and how to install the
  site as an app. See *Public online service* in the [technical documentation](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/docs/en/technical-documentation.md)
  ([Deutsch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/docs/de/technische-dokumentation.md)).
- **Relay:** `--no-listen` (PowerShell: `-NoListen`) switches off port forwarding – for a relay behind a reverse proxy on the same
  server, whose users could otherwise open ports on the server's `127.0.0.1`.
- **Hosted web app variant** (`tools/build_pwa.py`): eight applications (document, mail, notebook, presentation, web slides,
  spreadsheet, text editor, web inspector) showed program code instead of starting – the manifest link and the service worker
  registration were inserted inside their scripts. Fixed; the manifests also have the suite icon as PNG (192 and 512 px).

The applications themselves are unchanged since 1.5.0 (only their version number). Update the **relay** if you use `--no-listen`.

## Good to know

- **Small and medium files:** the applications keep their data in the browser's memory, so what they can handle is limited by the memory of one browser tab. They are made for everyday files, not for big data.
- **Saving:** in Chrome and Edge, saving writes directly to the opened file. Firefox downloads a new copy, which you then use to replace the old file.
- **Office files:** charts, cropped pictures and videos are kept; charts are written as pictures with their data (not as native Office charts). Keep the original file until you have checked the result.
- **Network functions** (SSH, FTP/SFTP, e-mail, PostgreSQL, MySQL, CalDAV, network from Python) need the small **relay** program on your computer, because browsers cannot open such connections themselves. It runs without installation or administrator rights: [`relay/python/relay.py`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/relay/python/relay.py) (Python) or [`relay/powershell/relay.ps1`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/relay/powershell/relay.ps1) (PowerShell). All other functions work without it.
- **Settings** are stored per origin: applications opened as files and applications served by the relay keep separate settings (move them with **⚙ Settings** → Export / Import, or with a workspace).
- **Help:** press `F1` in any application. Documentation: [user guide](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/docs/en/user-guide.md), [Benutzerhandbuch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.5.1/docs/de/benutzerhandbuch.md).
