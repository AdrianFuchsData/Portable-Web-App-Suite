Office, file, security, data science and network tools that run completely in the browser. **Every application is a single HTML file**: download it, open it in Chrome, Edge or Firefox, done. No installation, no administrator rights, no server, no internet connection needed. It also works on thin clients with only a browser, and on Windows, Linux and Android.

## What's new since 1.1.0

**Files across applications**
- **Open from and save into archives in every application.** *Open* and *Save as* ask: file system or an archive. The archive manager opens an archive from disk or creates a new one, asks for the folder and name, and *Save* in the application writes into the archive again. If the archive is closed, saving says so, and closing an archive with files still open elsewhere asks first and lists them. Can be switched off in the settings.
- **The Python notebook's file system works the same way:** other applications open files from it and save into it – clearly marked as living only in memory (gone when the page closes or Python restarts).
- **Examples for every application**, in English and German: `F1` → **📂 Examples** opens one, and `examples.zip` contains all of them.

**Python notebook**
- **More packages:** SciPy and scikit-learn; python-docx, python-pptx, XlsxWriter, pypdf and icalendar for office files; pg8000 and PyMySQL for databases; Jinja2, Markdown, tabulate and tqdm. statsmodels, shapely, pyproj and scikit-image can be added at runtime (described in the help).
- **JupyterLab keys:** select several cells (`Shift+↑/↓`, `Shift+click`), copy/cut/paste (`C`/`X`/`V`), delete with `D`, `D`, merge (`Shift+M`), move, run the selection.
- **Runs cells one after another**, and **stops on an error** (switchable). **Stop** restarts Python – or, when the notebook is served by the relay, **interrupts** the running cell with `KeyboardInterrupt` and keeps the variables (`I`, `I`).
- **Archives in Python:** mount an archive of the archive manager below `/mnt` (button or `await suite.archives.mount()`) and use `os`, `open`, pandas … on its files; changes go back into the archive after every cell.
- **Network from Python through the relay:** `requests` (also when the notebook is opened as a file); served by the relay also sockets – `smtplib`, `ftplib`, `imaplib`, `http.client`, database drivers – and **SSH/SFTP** with a Fabric-compatible `suite.ssh.Connection`. The header shows what is possible.
- **Terminal:** a bash-like shell on the Python file system with the usual commands (`ls`, `cp`, `grep`, `sed`, `sort`, `tar`, `zip`, …), pipes, redirections, globs, variables, history, Tab completion, shell scripts, `python` and `pip`, plus the interactive programs **less** and **nano**.
- `Tab` indents in cells; a tab character is `Ctrl+Alt+I` (also in the other code editors and text fields) or in the emoji and symbol picker (group *Spaces and tab*), for phones without a Tab key.

**Other applications**
- **Spreadsheet:** sorting and filtering; filters are kept in Excel files and work in LibreOffice and Excel.
- **Archive manager:** writes TAR.BZ2 and TAR.XZ; a **Close** button.
- **HTTP analyzer:** opens collections from other applications (and its examples).

**Relay**
- **Serves the applications** (`--serve FOLDER`) as cross-origin isolated pages – needed for the notebook's interrupt, sockets and SSH. The port stays configurable (`--port`).
- **Through a company proxy:** `--upstream-proxy http://proxy:3128` (also with credentials, or `env`) and `--no-proxy`. Both in the Python and the PowerShell relay.

**Fixes**
- The SSH engine no longer stops when an SFTP session is closed while data is pending.
- Several test flakes fixed (Firefox print preview, storage timing).

## Good to know

- **Small and medium files:** the applications keep their data in the browser's memory, so what they can handle is limited by the memory of one browser tab. They are made for everyday files, not for big data.
- **Saving:** in Chrome and Edge, saving writes directly to the opened file. Firefox downloads a new copy, which you then use to replace the old file.
- **Network functions** (SSH, FTP/SFTP, e-mail, PostgreSQL, network from Python) need the small **relay** program on your computer, because browsers cannot open such connections themselves. It runs without installation or administrator rights: [`relay/python/relay.py`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.2.0/relay/python/relay.py) (Python) or [`relay/powershell/relay.ps1`](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.2.0/relay/powershell/relay.ps1) (PowerShell). Start it with `--serve` and the folder of the applications to use the notebook's interrupt, sockets and SSH. All other functions work without it.
- **Settings** are stored per origin: applications opened as files and applications served by the relay keep separate settings (export and import them with **⚙ Settings**).
- **Help:** press `F1` in any application. Documentation: [user guide](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.2.0/docs/en/user-guide.md), [Benutzerhandbuch](https://github.com/AdrianFuchsData/Portable-Web-App-Suite/blob/v1.2.0/docs/de/benutzerhandbuch.md).
