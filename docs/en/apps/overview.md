# Overview

`overview.html` contains **all applications of the suite in one file** (about 90 MB, most of it the Python
notebook). It is the easiest way to get the suite onto a computer: copy one file, open it, and start any application
from there.

## Starting applications

The start page lists the applications by category. For each application:

| Button | Function |
|---|---|
| Open | starts the application in a new tab of the overview |
| ↗ | starts the application in a new browser window |
| 💾 | saves the application as its own HTML file (e.g. `texteditor.html`) |

The tabs at the top switch between the start page (▦ Apps) and the running applications; they keep their state while
you switch. A dot (•) marks unsaved changes; closing such a tab (×) or the overview asks first.

## Saving applications

**Save all apps…** saves every application as its own HTML file: in Chrome and Edge into a folder you choose, in
other browsers as the download `portable-web-app-suite.zip`. Single files are useful for computers that only need some
applications, or to open an application directly. Applications started from separate files can still pass files to
each other if they are kept **in one folder with their original names** (see “Open with…” in the user guide).

## Opening files

**Open file…** (or dropping a file onto the start page) asks which application should open the file and starts it in
a tab. In Chrome and Edge, saving in that application writes directly to the file.

## “Open with…” between applications

Applications started in the overview open files from other applications (for example a file in an archive, a file on
an SFTP server, an e-mail attachment) in a new tab. Saving there writes the file back to the application it came from.

## Keyboard shortcuts

On a Mac, use Cmd instead of Ctrl. `F1` (or `?`) shows this list in the application.

### Help

| Keys | Function |
|---|---|
| `F1` / `?` | show this list (outside of text fields) |

## On phones and tablets

The start page shows one application per row; the tabs scroll sideways. Applications run in the full width below the
tabs. Opening many applications at once needs a lot of memory; close the tabs you no longer need.
